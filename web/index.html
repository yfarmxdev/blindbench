02 / How it works

Four steps. Zero questions revealed.

Every step leaves something anyone can check.

01

Commit

An expert writes a secret test set. Only its Merkle root and a price go onchain.

02

Pay

Anyone pays in NEAR to get a model scored. The payment waits in escrow.

03

Score in a TEE

The model answers inside a NEAR AI Cloud enclave, which signs every answer. A TEE judge or hidden tests grade it.

04

Certify

The score and an evidence hash land on NEAR. Escrow pays the set's author.

03 / Proof

What a certificate proves

And what it doesn't prove yet.

The questions were fixed first

The set's Merkle root was onchain before any run, and each certificate copies it.

The answers came from the named model

Every answer is signed by a key held in an Intel TDX enclave. Verifying a certificate checks the hardware quote behind each key down to Intel's root certificate.

No question is published

Only TEE models are scored. The set's author and runner hold the questions. The evidence holds hashes and signatures, never questions or answers in the clear.

Still trusted today

The set's owner holds the questions and runs the grader. Checklist and rubric sets are graded by a TEE judge model named on the certificate. Next: the grader in its own enclave.

04 / Use it

Three ways in. One command each.

Live testnet contract. Setup is in the docs.

Eval authors

Publish a private set

Your questions stay with you. A hash and your price go onchain, and you are paid for every run.

node blindbench.mjs commit myset.jsonl --price 0.5
Model builders and buyers

Get a model scored

Pay into escrow from a leaderboard or the command line. The public runner is off in this version: see Status.

node blindbench.mjs request 4 Qwen/Qwen3.8-27B --deposit 0.5
Anyone

Verify a certificate

Click any leaderboard row, or recheck it from the command line. No account and no key.

node blindbench.mjs verify --cert 10
05 / Status

A working prototype, built for NEAR HACKATHON.

Our hackathon entry, running on NEAR testnet.

Works today

Real runs, real proofs

  • Every certificate here is real: run inside NEAR AI Cloud enclaves and recorded on the NEAR testnet contract.
  • Anyone can verify them, free, in the browser. No account and no key.
  • Five private sets with public leaderboards, and one bounty already paid out by the contract.
  • The whole flow runs from the repo in one command, offline, against a simulated enclave.
Not switched on yet

Runs on demand

  • New runs are not served in this version. You can pay: the request is recorded onchain and waits in escrow, but the runner is off, so no certificate is posted. After 24 hours you can take the payment back.
  • Testnet only. Test NEAR has no real value. There is no mainnet contract yet.
  • Paying from another chain stops at a live NEAR Intents quote.
Next

The full marketplace

  • Runs on demand on mainnet, in NEAR or USDC. The price covers inference, the author's share and a platform fee.
  • Grading in its own enclave, so the score no longer depends on trusting the set's owner.
  • Sets encrypted to the enclave, so one service can host many authors.
  • A listing on NEAR's Agent Market, so agents can pay for a private score.

See a full run now: npm run demo in the repo. Known limits are in the README.
